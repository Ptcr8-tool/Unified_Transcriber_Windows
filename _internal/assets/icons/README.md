# Studio action icons

このアプリのために作成した50種の線画アイコンです。24×24のSVGを編集元として同梱しています。

`svg/` は `currentColor` を使うベクター原稿、`png/` は同じ形状の18／20／24／28／36／48px画像です。Tk 8.6でも追加ライブラリなしで表示できるよう、実行時にはPNGを使用します。PNGのアルファ値を保ったままパレットだけを変更し、ライト／ダーク・無効状態・選択状態に合わせて配色します。フォント記号や絵文字への依存はありません。

SVGとPNGはアプリに含めて配布・変更できます。外部のアイコンライブラリやネットワーク取得は使用していません。

# 起動・セットアップの入口

インストーラー版はインストール時に作られるアプリのショートカットから起動します。以下はソース版や診断用の入口です。既存利用者の操作や自動化との互換性のため、今回の整理では削除していません。

| ファイル | 用途 |
| --- | --- |
| `start_gui.vbs` | Windows の Python ランチャー `pyw.exe -3.11` を使い、コンソールを表示せずに内部の起動スクリプトを開く。 |
| `start_gui.pyw` | `.pyw` の関連付けを使う代替入口。内部の起動スクリプトへ渡す。 |
| `_internal/start_gui.pyw` | 起動ログを記録し、GUI を起動する内部スクリプト。通常は直接選ばない。 |
| `_internal/tools/start_gui_console.bat` | コンソールに出力を表示する診断用。Python 3.11 のランチャーが必要。 |
| `_internal/tools/setup_all_cpu.bat` / `setup_all_gpu.bat` | 既存の CPU / CUDA 向け全プロファイル設定用。Python 3.11 のランチャーが必要。 |
| `_internal/tools/setup_bulk.bat` | プリセットなどを指定するコンソール用の一括設定入口。 |

旧 CLI の `--watch` も互換性のため維持しています。GUI のフォルダー監視とは別の入口です。処理済み音声や文字起こしの移動に失敗した場合、完了済みの文字起こしは入力フォルダーの一時ファイルとして保持し、エラーログにその場所を記録します。

テストファイルに残る `test_v*` の番号は、追加された機能や回帰の履歴を示す旧来の名前で、現在のアプリのバージョン番号を表しません。テスト選択や外部の参照を壊さないよう、ファイル名は維持しています。

# 設定・データの取り扱い

- 配布物には個人の認証トークン、設定JSON、録音、実際の会議文字起こし、診断ログを含めません。AIモデルと音声認識・録音用の追加環境は、選択した場合にセットアップ中またはアプリ内で取得します。
- セットアップexeには、アプリ本体と必要なPythonランタイムを同梱します。GUI・従来方式用のPython 3.11.18は公式ソースを固定してビルドし、方式②・録音用のPython 3.14.10はPython公式のNuGet配布を取得先・SHA-256を固定して同梱する構成です。利用者のグローバルPythonには依存しません。確認範囲は [検証資料](VALIDATION.md) に記録しています。
- Hugging Faceトークンの保存先としてWindows資格情報マネージャーを利用できます。アプリが保存した資格情報があれば優先し、なければ既存の `HF_TOKEN` 環境変数、次いで従来の設定を利用します。環境変数は暗号化された保管庫ではありません。
- 従来のsettings.jsonに保存された平文トークンは、資格情報への書き込み・読み戻しを確認でき、ほかのトークンと競合しない場合に限り、資格情報へ移して設定から削除します。失敗・競合時は元の設定を保持してログに通知します。旧版の別フォルダーの設定やユーザー環境変数は自動削除しません。
- 「トークンをsettings.jsonに平文保存する」を選んだ場合は、利用者のPC内に保存されます。新しいセットアップexeから導入したアプリの設定は、インストール先の `Data/settings.json` に保存します。従来のソース配布をそのまま使う場合は `%APPDATA%\UnifiedTranscriberV12\settings.json` です。
- 設定の書き出しで「認証トークンも含める」を選ぶと、そのJSONにも平文で含まれます。このファイルを共有・コミットしないでください。
- トークンを含む設定JSONをWindowsでインポートした場合は、資格情報へ保存し、アプリ設定には平文で残しません。設定エクスポートを削除するかどうかは利用者が決めてください。アプリのアンインストールやフォルダーの削除では、資格情報・環境変数・別フォルダーの設定は削除しません。不要な資格情報はアプリの詳細設定で削除できます。
- 標準名の書き出し設定JSON、settings.json、環境変数ファイル、ログ、モデル・実行環境、標準の録音・文字起こし保存先は `.gitignore` の対象です。任意名や任意フォルダーで保存したデータは、コミット前に個別に確認してください。
- ログにはファイルパス・デバイス名・認識結果、pipなどのセットアップ処理の詳細が含まれる場合があります。Hugging Faceトークンはマスクしますが、共有前に内容を確認してください。
- 画面例と同梱テストには架空のサンプルだけを使用しています。

新しいセットアップから導入するPython環境とモデルキャッシュはアプリのフォルダー内にまとめます。旧版から引き継ぐ際も、既存のWindowsユーザー環境変数の `HF_TOKEN`、旧版の外部設定、共有モデルキャッシュ、任意の保存先の録音は削除しません。それらを利用している他のアプリへ影響を与えないためです。

ログ・録音・文字起こし・結合・話者名編集・書き出しの既定保存先は、Windowsのドキュメント内に作る `UnifiedTranscriber` です。OneDriveなどへ移動済みのドキュメントはWindowsの登録先を使います。セットアップ時、またはアプリ内のセットアップ・詳細設定から共通保存先を変更できます。個別に設定した保存先は優先し、以前のファイルを自動移動しません。ドキュメントなどインストール先の外にある保存物は、アプリのアンインストールでは削除しません。

方式②・録音の旧Python環境を切り替える際は、新環境を別フォルダーで構築・確認してから置き換えます。構築失敗時は旧環境を保持し、共有モデルキャッシュと利用者の録音・結果を環境の置き換えに含めません。同じPython版の環境は再利用して依存関係を更新します。

Windowsの音声・動画処理には、FFmpeg公式ダウンロードページで案内されるGyan配布のFFmpeg／FFprobe 9.0.2を使用します。セットアップ時に固定した取得先とSHA-256を照合し、アプリのフォルダー内へ導入します。ハッシュの固定は、FFmpeg上流やGyanのデジタル署名を検証したことを意味しません。旧版から更新する場合は、録音・録画または利用中の認識方式のセットアップを再実行します。詳しい取得元と信頼範囲は [点検記録](AUDIT.md#windowsのffmpegffprobe) を参照してください。

CSVは本文を無損失で保持します。外部由来のCSVを表計算ソフトで開く際は、データ取り込みから本文・話者・ファイル名等を文字列として指定してください。先頭が `=`、`+`、`-`、`@` 等の値を数式として解釈したり、外部リンクを実行したりしないようにします。

更新確認は、公開されたGitHubの指定リポジトリへ認証情報なしで問い合わせます。非公開の間は公開向けの自動取得ができません。更新を適用する前には、取得ファイルのハッシュと署名付きビルド証明を確認し、確認できない場合は自動実行しません。詳しい確認範囲は [点検記録](AUDIT.md) を参照してください。

配布exeのAuthenticode署名は未付与です。公開タグから生成する署名付きビルド証明は、Windowsの発行元署名とは別の検証です。初回のexeは、案内した配布リポジトリのリリースから取得してください。証明による配布元の照合と、すべての依存ライブラリに脆弱性がないという判定も区別します。

方式②の既存AI環境を更新する場合は、本体更新後に一括セットアップを再実行します。他の従来方式にはモデル読込の確認事項が残るため、信頼できる配布元のモデルを使用してください。モデルや任意のPython環境を含めた安全性の詳細は [点検記録](AUDIT.md#ai環境に残る確認事項) を参照してください。

Python 3.15は必要なWindows用wheelがすべてそろっていないため、現時点では対応対象外です。方式②・録音には対応wheelのある更新構成、他方式には従来の互換構成を使用します。CUDAの事前表示はNVIDIA GPU・ドライバー情報に基づく見込みで、推論の成功や必要VRAMを保証するものではありません。

配布形式の比較では、実行ファイルの署名領域・構造・ハッシュを確認します。ファイルを公開の解析サービスへ自動送信しません。Windows Defenderの配布前検査と、その限界は [配布形式の記録](PACKAGING.md) を参照してください。

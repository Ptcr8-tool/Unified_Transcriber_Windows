# v1.0.0の検証範囲

ソースのテストと、実際のWindows配布物の検証は区別します。v1.0.0の結果は、対象コミットのWindowsワークフローと成果物で確認してください。

## 検証時の注意事項

- **ドラッグ＆ドロップ用依存の過去の検査：** `tkinterdnd2 0.6.4` について、外部の機械判定で警告されたことがあります。警告対象のファイル名・ハッシュは特定できておらず、その判定が感染か誤検知かは確定していません。配布物のWindows Defender検査はビルドごとに実施し、その結果を記録します。
- 依存wheelと上流のファイルの静的照合は [照合記録](tkdnd-064-static-report.json) を参照してください。一致は出所を調べた結果であり、無害性や誤検知の証明ではありません。ネイティブコードの逆解析や、すべての製品による実行時検査を終えたものではありません。
- アプリおよびセットアップexeにWindowsの発行元署名は付与していません。Smart App ControlやSmartScreenなどで拒否される可能性があります。
- 第三者ライセンス、FFmpegの対応ソース、モデルとMicrosoftランタイムの再配布条件は引き続き確認が必要です。[第三者ソフトウェアの情報](../../THIRD_PARTY_NOTICES.md)を参照してください。

## ソースの回帰テスト

ソースの自動テストでは、設定・出力・CSVの保護、セットアップ、キュー、録音処理、更新のURL・ハッシュ・証明・リポジトリIDの検査などを対象とします。表示環境やWindowsがない場合は、GUI・Windows固有の一部テストがスキップされます。スキップを成功扱いにはしません。

`VERSION`とアプリ本体の版番号を一致させ、配布するワークフローのリリースタグと照合します。旧バージョンを模したインストール移行試験は、テスト用に人工的に作成したデータによる検証であり、実際の以前のEXEを使った検証ではありません。

## Windows配布前の確認

「Actions → Build Windows installer」の対象コミットで、以下を確認します。

- 固定した入力とハッシュに基づくCPython・NSIS・依存物の取得とビルド。Microsoftランタイムの署名確認。
- 実際のセットアップ、同梱Python・Tk・SSL・venv、ネイティブ起動器、修復・削除と登録解除。
- 設定・モデル・録音・結果の保護、長いパスや日本語を含む引数、人工的な旧版データからの移行。
- 録音環境・CPU認識環境の読み込み、検証済みFFmpeg／FFprobeによる媒体テスト。
- Defenderの検査状態・対象・結果・前後のハッシュ。検査が実行できない場合は成功扱いにしない。

公開タグから生成する出所証明は、リポジトリID・ワークフロー・タグを検証するためのもので、Windowsの発行元署名やウイルス検査ではありません。非公開リポジトリの配布物は、公開向けの証明を伴う更新の正常系を確認できません。

## 実機での確認が必要な範囲

次の項目は、このソースの自動テストだけでは保証できません。

- 実際のWindows PC上のGame Bar録画開始・停止、ウィンドウ選択、ホットキー。
- 実際のマイクとPC音の収録、左右分離、映像との同期。
- Windowsのドラッグ＆ドロップ、通知領域、自動起動。
- モデルの実ダウンロード、Hugging Face認証、CPU／GPUでの認識精度と速度。
- 利用するPCやセキュリティ製品による警告・拒否。

認識環境の既知の制約は [安全性の点検](AUDIT.md#ai環境に残る確認事項) を参照してください。初回セットアップ後は短いサンプル音声で確認してください。

# v1.0.4

- **終了後の画面整理：** ×で通知領域へ閉じた後に再表示すると、正常完了した一覧項目と保存済み文字起こしのプレビューをクリアします。処理中・未完了・失敗・一部完了・中断の内容は保持します。単なる最小化ではクリアしません。録音・TXT・CSV・診断ログなどの保存済みファイルは削除しません。
- **TOPの停止を2段階に：** 1回目は通常停止で保存・設定済みの文字起こし・変換を続行し、もう一度押すと全停止します。誤ダブルクリック防止のため切り替え直後0.6秒間は全停止を受け付けません。
- **停止ショートカットの通知：** Windowsの無音通知で停止の受付を知らせます。保存完了とは区別し、作業中のウィンドウを前面へ移動しません。連打による同種通知を2秒間抑制します。Windows側の通知設定で表示されない場合があります。
- **録音の初期入力：** 新規設定時はマイク＋PC再生音を選択します。保存済みの入力元設定は維持します。
- **日本語・英語の表示：** インストーラーの最初とアプリの設定から選択できます。新規導入時はWindows表示言語を参照し、未対応言語は英語、取得失敗時は日本語を候補にします。音声認識の言語とは独立しています。一部の詳細な診断文などは日本語が残ります。
- **ショートカットの事前確認：** キー入力時・保存前にWindowsへの登録可否を確認し、使用中や予約済みのキーを事前に表示します。登録後の競合検出も維持します。
- **自動更新の安定化：** 更新EXEの転送期限を30分、アセット通信の待ち時間を45秒に拡大。取得量・進捗表示とキャンセルを改善し、SHA-256とビルド出所証明の検証は維持します。通信切断後の途中再開には未対応です。

v1.0.3および検証版v1.0.3-a／v1.0.3-bから、同じインストール先を指定して更新できます。更新前に常駐も含めてアプリを完全終了し、重要な設定・録音・文字起こしをバックアップしてください。旧版の自動更新がタイムアウトする場合は新しいセットアップEXEで手動更新できます。

**このEXEにはAuthenticodeの発行元署名がありません。** GitHubのビルド出所証明はWindowsの発行元署名とは異なります。端末の保護機能を無効にせず、組織の規定に従って使用してください。

## v1.0.3

- **モデル取得の修正：** Hugging FaceのTLS検証にWindowsの信頼済み証明書を使い、WinError 1314につながるキャッシュ作成の並列競合を抑えます。証明書検証やホスト名検証は維持します。
- **方式③・⑤の環境構築：** pyannoteとNumPyの互換性を固定し、必要なソース配布パッケージをハッシュ検証付きで導入できるようにしました。導入済みの③・④・⑤は、今回の更新後に該当方式のセットアップを再実行してください。
- **処理中断からの回復：** Qwenはチャンク単位、faster-whisperは複数区間ごとに途中結果を同じ出力フォルダーの `.*.partial` に追記します。異常終了時のTXT全文消失リスクを軽減します。途中ファイルは未完成で、話者名などが暫定の場合があります。
- **後片付け前の書き込み：** 最終TXTを一時WAV削除前に確定します。発生した例外は一時WAVの後片付けより前に `.error.log` へ記録します。
- **データの扱い：** 途中結果はローカルに保存され、正常完了時に削除します。異常終了時は調査・復旧用に残るため、発言内容の取り扱いに注意してください。
- **セキュリティ製品：** Apex Oneによる挙動監視の停止・隔離を回避・無効化するものではありません。再発する場合は端末管理者に検出時刻とSHA-256の照合を依頼してください。コード署名は未付与です。

v1.0.0、v1.0.0-a、v1.0.0-b、検証用v1.0.1、正式版v1.0.2、検証版v1.0.2-aからv1.0.3へ更新できます。設定と既存の文字起こしファイルは維持されます。

## v1.0.2

- 上部メニューを説明付きの表示へ再設計しました。「録音・録画」と「ツール」は見出しの下から操作を直接選べます。「設定・診断」は左の分類と右の操作一覧で探せます。
- メニューをボタンの近くに重ねて表示します。上下キー、Home／End、Enter・Space、Escで操作でき、閉じると元のボタンへフォーカスが戻ります。
- Windowsでメニューを続けて切り替えたとき、開いたメニューが閉じてしまう問題を修正しました。
- 文字起こしの発話間の空行を既定0行に変更しました。設定で0〜10行に変更できます。
- 話者名編集後のTXT／CSVを、元のファイルと同じフォルダーへ別名保存するようにしました。
- アプリ内ヘルプと同梱の操作ガイドを更新しました。

### Windowsの発行元署名

今回のexeにはAuthenticode署名がありません。Windowsやブラウザーで警告が表示される場合があります。GitHubのビルド出所証明とSHA-256チェックサムを添付します。

## v1.0.0

初期版として、音声・動画の文字起こし、リアルタイム録音、Game Bar連携、話者名編集、結合・変換をまとめています。

- 認識方式② faster-whisper + Resemblyzerを推奨し、CPU／GPUと音声認識モデルを選べます。
- 人名や団体名などを認識時のヒントとして登録できます。認識後の自動置換は行いません。
- マイク・PC音の録音、左右への分離、ライブ文字起こし、録音後のキュー追加に対応します。
- ライト／システム／ダークの切り替え、通知領域での待機、ショートカットのカスタマイズを選べます。
- 共通保存先や設定の移行、処理結果の確認、オフライン操作ガイドを利用できます。

### 未署名によるWindows警告について

- **Windows発行元署名なし：** 配布exeにはAuthenticode署名がありません。ダウンロード警告、SmartScreenの警告、Smart App Controlによる実行拒否が起こる場合があります。Windowsの保護機能の無効化は推奨しません。
- 配布先はGitHub Releasesです。`SHA256SUMS.txt` によるハッシュ検証も可能です。
